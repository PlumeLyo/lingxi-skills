# 会话收尾·四层同步（v6）

## 核心路径

| 用途 | 路径 |
|------|------|
| 共享记忆 | `D:\Obsidian\人生系统知识库\0-记忆档案\agent-shared-memory.md` |
| Obsidian | `D:\Obsidian\人生系统知识库\` |
| 作品集 | `C:\Users\羽涅\Desktop\work\作品集\` |
| 归档 | `C:\Users\羽涅\Desktop\work\归档\` |

## 流程

### 1. 增量记忆同步

回顾本会话，检查是否有需要持久化的变化：

**必写信号**（立即写入各Agent自身记忆系统）：
- 用户说"记住/别再/以后/下次"
- 用户纠正行为并期望长期遵守
- 新路径/新工具/新账号
- 被记录为决策的选择

**模糊信号**（有价值但不紧急，写入当日日志）：
- 某个坑的新发现/细节补充
- 暂时无法归类的零散发现

写入方式按各Agent自身能力选择（千问办公用 memory 工具，Codex 写本地文件，灵犀用 edit_memory）。无变化则跳过。

### 2. 共享记忆·决策日志

读取 `agent-shared-memory.md`，更新：
- 任务状态行（当前 Agent 行）
- 决策日志：新增 `| MMDD | Agent名 | 变更摘要 |`

单行摘要，≤30字。

### 3. 工作区文件分流

| 文件类型 | 去向 |
|---------|------|
| .docx/.pptx/.xlsx/.pdf | → `work\归档\` |
| .jpg/.png/.html 成品 | → `work\作品集\` |
| .md 笔记/分析 | → Obsidian 对应模块 |
| .docx 记忆档案类 | 先转 .md → Obsidian，原档 → `work\归档\` |

Obsidian 模块映射：`0-记忆档案/` `3-学习笔记/` `4-内容创作模块/彳亍时刻/` `4-内容创作模块/屋托邦指南/` `5-知识库模块/` `6-个人成长模块/`

无新增文件则跳过。

### 4. 清理

删除本会话产生的临时/中间文件（对话片段、草稿、转换中间产物等），保留最终交付物。各Agent按自身工作区路径清理。

## 周期维护

以下两项仅达到触发间隔时执行，否则跳过。

### Dream（≥7天）
检查决策日志上次 Dream 日期。间隔≥7天时快速扫描：决策日志>30天条目可否压缩、温记忆文件>60天是否需更新、长期未用 skill 是否可清理。超时跳过，结果追加到决策日志。

### Distill（≥30天）
检查决策日志上次 Distill 日期。间隔≥30天时扫描：近30天重复≥3次的操作→建议固化为 skill/规则/SOP，产出建议清单交用户确认。超时跳过，结果追加到决策日志。

## 摘要模板

```
## 收尾
1. 记忆：xxx（或无新增）
2. 决策日志：+N条
3. 文件分流：归档 xxx / 作品集 xxx / Obsidian xxx（或无新增）
4. 清理：删除 x 个临时文件（或无）
5. Dream/Distill：xxx（或跳过）
```

## 规则
- 顺序执行，失败静默跳过
- 各Agent按自身能力选择写入方式，本 skill 只定义"做什么"不绑定"用什么工具"
- Dream/Distill 不阻塞其他步骤
- 增量写入遵循"不动>少动>轻动"：明确信号立即写，模糊信号先入日志
