## 流程

### 0. 云端记忆·增量校验
回顾会话上下文，校验以下变化是否已在会话中通过增量检查点写入（`edit_memory`）：
称呼/笔名/职位/所在地 | 偏好(触发词/格式/流程) | 路径/工具/技能变更 | 关键决策

- **已写入** → 跳过（增量在会话中已完成）
- **未写入** → 补写（用 `edit_memory`，单次 ≤50 token，先 `get_memory` 再编辑）
- **无变化** → 跳过

追加本轮决策到决策日志（格式：`MMDD: 摘要`）。

### 1. Scratchpad 路由
检查会话中是否产生过"有价值但未归类"的信息（灵犀内部 scratchpad）：
- 属于热记忆 → `edit_memory` 写入
- 属于温记忆 → 更新对应 OB 文件
- 属于冷记忆 → 更新对应 OB 文件
- 暂时无法归类 → 追加到决策日志备注

无 scratchpad 内容则跳过。路由后清空 scratchpad。

### 2. Dream（≥7天触发）
检查决策日志中上次 Dream 的日期：
- 间隔 < 7天 → 跳过
- 间隔 ≥ 7天 → 执行以下检查，结果追加到决策日志（如 `0612: Dream#1 - 结果摘要`）

**Dream 检查清单**：

```
□ 热记忆（云端 user）
  - 决策日志：>30天的条目是否可压缩？（保留结论，删除过程）
  - 触发召回表：是否有失效条目？（已不用的工具/路径）
  - 整体体积：是否超过 2000 token？是则考虑压缩冷记忆索引

□ 温记忆（OB 文件）
  - 最后修改 > 60天 → 对比最近实际使用经验，是否需要更新
  - 内容与其他温记忆文件是否有重复/冲突
  - 文件内引用的路径/链接是否有效

□ 冷记忆（OB 文件）
  - 是否有 >90天未访问的文件？
  - 坑位文件：该坑是否已修复？已修复则标记归档
  - 案例文件：是否有新的相关案例应补充？

□ 灵犀 Skill
  - 是否有 skill 长期未使用？
  - skill 描述是否需要更新？
```

Dream 时限：≤5分钟检查，超时跳过未完成项。

### 3. Distill（≥30天触发）
检查决策日志中上次 Distill 的日期：
- 间隔 < 30天 → 跳过
- 间隔 ≥ 30天 → 执行以下扫描，结果追加到决策日志（如 `0612: Distill#1 - 发现N个重复模式`）

**Distill 扫描逻辑**：

```
1. 回顾最近 30 天的决策日志
2. 识别重复模式：
   - 同类操作出现 ≥ 3 次（如反复手动描述同一流程）
   - 同类问题被重复解决（如每次都要说明某个工具用法）
3. 对每个重复模式评估：
   - 能否固化为 skill？→ 建议创建/更新 skill
   - 能否固化为规则？→ 建议写入热记忆
   - 能否固化为 SOP？→ 建议写入温记忆 OB 文件
4. 产出建议清单交给用户确认，不自动创建 skill
```

Distill 时限：≤5分钟扫描，超时跳过。

### 4. nmem 本地
```bash
nmem m add "<变化摘要>"
```
服务未启动则静默跳过。

### 5. WPS知识库
```bash
python sync-memory.py --file <临时md>
```

### 6. 工作区文件分流

| 文件类型 | 去向 |
|---------|------|
| .docx/.pptx/.xlsx/.pdf | → `work\归档\` |
| .jpg/.png/.html 成品 | → `work\作品集\` |
| .md 笔记/分析 | → Obsidian 对应模块 |
| .docx 记忆档案类 | 先转 .md → Obsidian，原档 → `work\归档\` |

Obsidian 模块映射：`0-记忆档案/` `3-学习笔记/` `4-内容创作模块/彳亍时刻/` `4-内容创作模块/屋托邦指南/` `5-知识库模块/` `6-个人成长模块/`

### 7. IMA 分发（可选）
最终版/高价值 → 小满知识库。

### 8. 清理
删除临时/中间文件。

## 规则
- 顺序执行，失败静默
- `.docx` 不进 Obsidian
- 仅 `/neat` 命令触发 neat-freak，本技能与其不冲突
- 增量写入遵循"不动>少动>轻动"：明确信号立即写，模糊信号先 scratchpad
- Dream/Distill 不阻塞其他步骤，超时则跳过未完成项继续后续流程

## 会话中增量检查点规则（灵犀行为约束）

以下信号出现时立即 `edit_memory` 写入，不等收尾：
- 用户说"记住/别再/以后/下次/今后"
- 用户纠正灵犀行为并期望长期遵守
- 用户分享新路径/新工具/新账号
- 操作选择被记录为决策

以下信号暂存 scratchpad，收尾时路由：
- 有价值但不紧急的上下文信息
- 某个坑的新发现/细节补充
- 暂时无法归类到热/温/冷的零散发现
