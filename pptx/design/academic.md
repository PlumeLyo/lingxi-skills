# 学术报告 / 论文答辩

> 适用场景：论文答辩、科研组会、学术会议演示、科研项目报告、项目进展汇报等
> 风格锚点：Nature/Science 论文配图风格 + 学术会议演示标准

## 设计理念

- **内容为王**：视觉服务于学术内容；所有设计决策以清晰传达研究成果为优先，避免任何过度装饰
- **严谨规范**：遵循学术表达规范，图注完整，数据来源可追溯。**严禁幻觉——确保所有内容有真实、完整的引用！**
- **逻辑清晰**：研究逻辑链应一目了然——问题 → 方法 → 结果 → 结论，每页服务于一个清晰的论证节点
- **朴素专业**：不追求视觉华丽，追求专业性和可信度。学术报告的说服力来自数据和逻辑，而非视觉效果
- **信息丰富**：学术报告页面不能空洞；应有充足的研究内容和数据支撑，每页承载实质性的学术信息
- **忠实于来源**：优先复用论文/报告中的原始图表、数据和表述，保持与来源材料的一致性，不进行无依据的二次加工

## 信息密度：高

- 每页聚焦一个研究点，内容区域填充率 **70-85%**，留白控制在 15-30%
- 图表和数据是核心内容载体；文字用于解释和逻辑连接
- 公式、表格和图表可以密集排列，但必须保持清晰的注释、编号和视觉层级
- 每页可在底部或末尾设置摘要结论，用加粗或强调色突出该页的核心发现
- 高信息密度不等于杂乱：通过对齐、分栏和间距控制确保高密度下的可读性

> **核心原则：评委/听众能从每页准确提取一个研究发现，并理解其支撑证据**

## 图文比例：图表主导

- 内容页推荐比例：约 35% 文字 + 55% 图表/原始图/公式/表格 + 10% 留白
- 结果页面绝对以图表为中心，文字仅作为注释和关键解读
- 鼓励使用流程图和示意图展示研究框架、方法流程和系统设计
- 避免纯文字页面（研究背景综述页除外）；力求图文融合
- 来源中的原始图表应优先直接复用（见"内容表达技巧"中的"原始图复用"策略）

## 配色指导

- **学校主题色**：使用目标高校的校徽/VI 标准色作为主色——这是学术演示配色方案的首要优先级。当用户指定高校名称时，查找该高校的标准色并用作主色。如果用户未指定高校，则遵循以下配色指导
- **整体调性**：配色方案应服务于内容可读性，追求简洁、克制、专业的风格。颜色总数尽量少，避免用视觉复杂度分散听众对学术内容的注意力
- **主色逻辑**：建议用单一低饱和度、稳重的主题色锚定整体设计，用于标题、导航栏、关键注释和其他核心视觉锚点。色调应与场景相符——学术演示需要沉稳、严肃的色调，而非鲜艳、动感的颜色
- **背景与正文**：背景应保持足够亮度，确保图表、公式和文字的高可读性；正文颜色必须与背景形成清晰对比，避免视觉疲劳
- **图表颜色**：图表颜色以可区分性为首要目标，同时避免过于刺眼或过于相似的颜色。参考主流学术期刊（如 Nature/Science）的配色调色板，保持专业性
- **强调色**：仅用于突出关键发现、核心结论或显著性标记；使用应克制，不过度延伸
- **总体禁忌**：避免大面积深色背景用于正文区域（影响图表可读性）、高饱和荧光色，以及多种高对比色同时大面积使用造成的视觉混乱

## 字体指导

- **标题**：无衬线加粗（例如 QuattrocentoSans Bold、MiSans Bold），简洁清晰，确保在投影环境中的易读性
- **正文**：无衬线常规（例如 QuattrocentoSans、MiSans），确保投影仪上的可读性
- **公式/代码**：公式使用 LaTeX 渲染；代码可使用正文字体
- **英文参考文献/术语**：与正文保持相同字体族；不切换字体
- 字号层级：封面标题 36-44px，页面标题 26-32px，副标题（表N / 图N / 分析节标题）22-26px，正文分析 18-22px（页面文字内容少时用 22px，适中时用 20px，较多时用 18px；不得低于 18px），脚注、来源注释、导航文字 12-16px

## 内容页

- **导航栏**：建议设置与页面宽度/高度匹配的水平或垂直导航栏，章节标题均匀分布，当前章节用带主题边框的白色矩形和可读文字颜色突出显示，帮助听众跟踪演示进度和整体结构；导航栏格式灵活
- **页面标题**：使用描述性短语（例如"实验结果：多指标性能对比"），不超过一行；标题应直接传达该页的研究点
- **高校 logo**：当用户指定高校名称时，建议在线搜索高校 logo（或从用户上传的附件中提取）并放置在每页统一的固定位置，清晰标明演示机构
- **内容区域**：
  - 单栏分析结构（纵向叙述）
  - 左图右析结构
  - 上图下结结构
  - 双图对比结构
  - 数据表格 + 结论结构
- **编号与引用**：所有图表应有标准编号（例如表1、图2等）；图表必须有完整的标题、图例、坐标轴标签和单位注释
- **参考文献引用**：正文引用的参考文献必须使用规范的引用格式（见"叙事风格"中的引用格式要求）。如果参考文献有在线链接（如 DOI 或论文主页），可以使用 `<a href="url">` 超链接指向原文
- **底部区域**：页面左下角的脚注、参考文献上标或补充说明；页码固定在右下角

## 叙事风格：论证驱动

- **整体结构**：按照经典学术论文结构组织幻灯片——背景与问题、相关工作、方法、实验设计、结果分析、结论与未来工作
- **语言风格**：客观严谨，使用学术语言，避免主观夸张和模糊表述。**严禁幻觉——确保所有内容有真实、完整的引用！**
- **引用格式要求**：正文引用相关工作时，必须标注参考文献编号（例如 [1]、[2-4]），编号与末尾参考文献列表一一对应。引用格式应遵循用户指定的标准（例如 GB/T 7714、APA、IEEE 等）；若用户未指定，中文答辩默认使用 GB/T 7714 格式，英文场景默认使用 APA 格式
- **忠实引用**：根据原文忠实引用相关工作的核心观点和结论；不得捏造或推测。每条引用都必须可追溯到原始文献
- **参考文献页（必须）**：幻灯片末尾必须包含专门的参考文献页，列出正文中所有引用的参考文献，格式统一，顺序编号。每条文献应包含作者、标题、期刊/会议名称、年份等关键信息。如果参考文献较多，可以分两页排列，使用小字号（12-16px）紧凑排列

## 内容表达技巧

- **原始图复用（优先）**：学术演示应优先使用论文或报告中的原始图表，而非重新绘制。原始图表保留了完整的数据精度、注释标准和学术格式；重新绘制可能引入错误或遗漏。复用时，保持原图的分辨率和清晰度；必要时在图旁添加文字解读或箭头标注以突出关键发现
- **实验图表**：折线图（趋势对比）、柱状图（方法对比）、散点图（相关性分析）、雷达图（多维对比）等；所有图表必须有完整注释。pptd.md 中未定义的常见图表类型（如瀑布图）可以用形状 + 文本框组合构建
- **数据表格**：方法对比表（行为方法，列为指标），最佳结果用加粗或强调色突出显示；表格必须有表头和编号
- **流程图/架构图**：使用形状、箭头和文字说明研究方法流程或系统架构，适合展示方法论和实验设计
- **公式**：关键公式独立居中显示，用 LaTeX 渲染，公式前后有变量说明
- **项目符号列表**：研究贡献、实验设置、消融实验结论等使用有序列表呈现，简洁清晰
- **参考文献**：完整参考文献列表在末尾专页；内容页脚注可包含该页引用的简略关键参考文献

## 装饰禁忌

| 禁忌 | 替代方案 |
|--------|---------|
| 华丽背景/纹理 | 纯白、极浅灰色或其他简洁背景 |
| 装饰性图标/插图 | 科学示意图和数据图表 |
| 艺术字/文字特效 | 标准学术字体，通过字重和字号区分层级 |
| 无注释图表 | 完整注释：标题、坐标轴标签、图例、单位、数据来源 |
| 渐变色和阴影效果 | 扁平纯色，保持简洁的学术图表标准 |
| 过度视觉效果 | 简洁克制；内容本身才是焦点 |
