<string_safety_rules>
**这是最高优先级的规则，违反将导致代码无法运行。**

1. **统一使用单引号定义字符串**：所有 Python 字符串字面量一律使用单引号 `'...'`，禁止使用双引号 `"..."`。
   - 正确：`run.text = '标题文字'`
   - 正确：`rPr.set(qn('a:eastAsia'), '微软雅黑')`
   - 错误：`run.text = "标题文字"` ← 禁止
   - 错误：`rPr.set(qn("a:eastAsia"), "微软雅黑")` ← 禁止
   - 唯一例外：docstring（三引号 `"""..."""`）照常使用双引号三引号。

2. **禁止嵌套引号**：字符串内部不得包含未转义的与外层相同的引号字符。
   - 若字符串内容含单引号（如英文缩写 it's），使用双引号包裹该字符串：`"it's a test"`。
   - 禁止在双引号字符串内嵌套双引号，禁止在单引号字符串内嵌套单引号。

3. **禁止中文弯引号**：代码中不得出现 "\u201c" 和 "\u201d"。
   - 中文内容若需要引号，统一使用中文全角单引号 '' 或直接省略。

4. **禁止四引号写法**：不得输出形如 `""内容""` 的四引号模式。

5. **每行引号必须成对**：输出的每一行代码中，单引号数量必须为偶数（docstring 行除外）。

6. **图片路径使用单引号**：`slide.shapes.add_picture('/path/to/image.png', ...)`

7. **qn() 参数使用单引号**：`qn('a:eastAsia')` 而非 `qn("a:eastAsia")`。

8. 使用page_info中提供的图标信息 来添加装饰性的图标。 禁止使用emoji图标。
</string_safety_rules>

<design_rules>
设计禁忌速查
- **不要居中对齐正文**——段落和列表使用左对齐；仅标题居中
- **不要忽视字号对比**——标题需要 36pt 以上，才能与 14-16pt 正文区分开
- **不要随意混用间距**——选定 0.3 英寸或 0.5 英寸间距后保持一致
- **不要使用低对比度元素**——图标和文字都需要与背景有强烈对比；避免浅色背景上的浅色文字，或深色背景上的深色文字
- **绝不在标题下方使用装饰线**——这是 AI 生成幻灯片的典型特征；用留白或背景色替代
</design_rules>

<code_requirements>
1. 函数签名固定为 `build_slide_XX(slide)`，其中 XX 是页码（两位数字，如 01、02）。
   函数只接收一个参数 slide（python-pptx Slide 对象），不接收其他参数。 slide对象已由外部构建， 并设置好了背景。
2. 页面的所有内容（标题文字、正文文字、图片路径等）必须直接硬编码在函数体内，不要使用任何外部变量或参数。
3. **优先使用 gen_script 工具函数**：构建目录下已提供 `gen_script.py` 工具函数库，包含以下封装函数，请优先使用它们来替代重复的底层代码：
   - `add_textbox(slide, left, top, width, height, word_wrap=False)` → 创建文本框，返回 (textbox, text_frame)
   - `add_paragraph(tf, text, font_size, font_color, bold, font_name, alignment, space_before, space_after)` → 添加段落并设置样式，返回 (paragraph, run)，自动处理中文字体
   - `set_run_style(run, text, font_size, font_color, bold, font_name)` → 设置已有 run 的样式（支持部分更新）
   - `add_rect(slide, left, top, width, height, fill_color, line_visible, line_color, line_width)` → 创建填充矩形
   - `add_rounded_rect(slide, left, top, width, height, fill_color, corner_radius, line_visible, line_color, line_width)` → 创建圆角矩形卡片，一行搞定
   - `set_shape_opacity(shape, opacity_percent)` → 设置形状透明度（0-100）
   - `add_picture(slide, image_path, left, top, width, height)` → 安全添加图片（自动 try/except）
4. 使用 `from gen_script import add_textbox, add_paragraph, set_run_style, add_rect, add_rounded_rect, set_shape_opacity, add_picture` 导入工具函数。
5. 使用 `from pptx.util import Inches, Pt, Emu` 进行尺寸设定，推荐使用 Inches 和 Pt。
6. 颜色使用 `from pptx.dml.color import RGBColor`，格式 `RGBColor(0xRR, 0xGG, 0xBB)`。
7. 文本对齐使用 `paragraph.alignment = PP_ALIGN.LEFT/CENTER/RIGHT`。
8. 代码必须可直接运行，不依赖任何外部变量。
9. 严格按照 design_spec 中的配色和字体系统设置样式。
10. 禁止实现页面背景，如背景图片、背景色等。 slide的背景已由 set_background 函数统一设置，本函数只负责页面内容（标题、正文、内容图片、装饰形状等），不要重复设置背景。
11. 对于 gen_script 未覆盖的操作（如图表、特殊形状），仍可直接使用 python-pptx 原生 API。
12. **【尺寸计算类型安全】** 所有参与尺寸算术运算的变量必须统一为 Inches()/Pt()/Emu() 对象或统一为普通数字，禁止混用。例如 `total_width = {数字}`（float）与 `gap = Inches({数字})`（EMU）相减会导致结果为负值，造成卡片消失、文本堆叠等严重布局错误。
</code_requirements>

### add_textbox - 创建文本框
文本框的宽高 需要根据文本内容,按照下面的估算规则进行估算:
	规则：
	  - CJK 字符宽度 = 1.0 × 字号 * 72 Inches
	  - 其他字符宽度  = 0.6 × 字号 * 72 Inches
	  - 粗体宽度额外增加 10%
	  - 高度 = 1.2 × 字号 * 72 Inches
```python
# 创建文本框，返回 (textbox, text_frame)
txBox, tf = add_textbox(slide, Inches(<left>), Inches(<top>), Inches(<width>), Inches(<height>)) # 默认开启自动换行
txBox, tf = add_textbox(slide, Inches(<left>), Inches(<top>), Inches(<width>), Inches(<height>), word_wrap=False) # 对于明确需要单行显示的如 标题、目录项序号，关闭自动换行
```

### add_paragraph - 添加段落（一行搞定文字样式 + 中文字体）
```python
# 添加段落并设置完整样式，自动处理 rPr + a:eastAsia
p, run = add_paragraph(tf, '<标题文字>', font_size=Pt(<size>), font_color=RGBColor(<r>, <g>, <b>),
                       bold=True, alignment=PP_ALIGN.LEFT)

# 添加正文段落
p, run = add_paragraph(tf, '<正文内容>', font_size=Pt(<size>), font_color=RGBColor(<r>, <g>, <b>))

# 带段前段后间距的段落
p, run = add_paragraph(tf, '<要点文字>', font_size=Pt(<size>), space_before=Pt(<space>), space_after=Pt(<space>))

# 带倍数行距的段落（1.5 倍行距）
p, run = add_paragraph(tf, '<正文内容>', font_size=Pt(<size>), line_spacing=1.5)

# 带固定行距的段落（20 磅行距）
p, run = add_paragraph(tf, '<正文内容>', font_size=Pt(<size>), line_spacing=Pt(20))

# 综合示例：段落间距 + 行距
p, run = add_paragraph(tf, '<多行正文>', font_size=Pt(<size>),
                       space_before=Pt(<space>), space_after=Pt(<space>),
                       line_spacing=1.5)

# 添加空 run（后续手动设置）
p, run = add_paragraph(tf, font_size=Pt(<size>))
```

### set_run_style - 设置已有 run 的样式

```python
set_run_style(run, text='<新文字>', font_size=Pt(<size>), font_color=RGBColor(<r>, <g>, <b>), bold=True)

# 仅修改部分属性
set_run_style(run, font_color=RGBColor(<r>, <g>, <b>))
```

<chart_guidelines>
**图表是数据页面的核心视觉元素。python-pptx 原生支持柱状图、折线图、饼图、环形图等多种图表类型，必须使用 `slide.shapes.add_chart()` 创建，严禁用矩形、圆形等基础 shape 手绘图表。**

### 为什么必须用原生图表 API
- 用 shape 拼凑的"图表"没有坐标轴、网格线、数据标签，视觉效果极差
- 原生图表支持自动缩放、数据标签、图例、坐标轴格式化等专业特性
- 原生图表在 PowerPoint 中可以双击编辑数据，shape 拼凑的则完全不可编辑

### 图表 API 基本用法

```python
from pptx.chart.data import CategoryChartData
from pptx.enum.chart import XL_CHART_TYPE, XL_LEGEND_POSITION, XL_LABEL_POSITION
from pptx.util import Inches, Pt

# 1. 准备数据
chart_data = CategoryChartData()
chart_data.categories = ['<类别1>', '<类别2>', '<类别3>', ...]  # 横轴标签
chart_data.add_series('<系列名称>', (<数值1>, <数值2>, <数值3>, ...))  # 数据系列

# 2. 创建图表（返回 chart 对象和 shape 对象）
chart_frame = slide.shapes.add_chart(
    XL_CHART_TYPE.COLUMN_CLUSTERED,  # 图表类型
    Inches(<left>), Inches(<top>),   # 位置
    Inches(<width>), Inches(<height>), # 尺寸
    chart_data                         # 数据
)
chart = chart_frame.chart
chart.has_legend = False  # 是否显示图例

# 3. 设置坐标轴
value_axis = chart.value_axis
value_axis.has_title = True
value_axis.axis_title.text_frame.paragraphs[0].text = '<单位>'
value_axis.axis_title.text_frame.paragraphs[0].font.size = Pt(<size>)
value_axis.axis_title.text_frame.paragraphs[0].font.color.rgb = RGBColor(<r>, <g>, <b>)
value_axis.major_gridlines.format.line.color.rgb = RGBColor(<r>, <g>, <b>)
value_axis.major_gridlines.format.line.width = Pt(<width>)
value_axis.format.line.color.rgb = RGBColor(<r>, <g>, <b>)

category_axis = chart.category_axis
category_axis.tick_labels.font.size = Pt(<size>)
category_axis.tick_labels.font.color.rgb = RGBColor(<r>, <g>, <b>)

# 4. 设置数据系列颜色
plot = chart.plots[0]
plot.gap_width = <gap>  # 柱间距（0-500，推荐 80-150）
series = plot.series[0]
series.format.fill.solid()
series.format.fill.fore_color.rgb = RGBColor(<r>, <g>, <b>)  # 柱体颜色

# 5. 添加数据标签
plot.has_data_labels = True
data_labels = plot.data_labels
data_labels.font.size = Pt(<size>)
data_labels.font.color.rgb = RGBColor(<r>, <g>, <b>)
data_labels.number_format = '<格式>'  # 如 '#,##0' 或 '0.0"%"'
data_labels.show_value = True

# 6. 设置图表背景（透明或填充色）
chart_spPr = chart_frame._element.find(qn('p:spPr'))
if chart_spPr is None:
    chart_spPr = chart_frame._element.find('.//' + qn('p:spPr'))
if chart_spPr is not None:
    # 方式1：设置为透明背景（推荐，与页面背景融合）
    if chart_spPr.find(qn('a:noFill')) is None:
        etree.SubElement(chart_spPr, qn('a:noFill'))

    # 方式2：设置为纯色背景
    solidFill = chart_spPr.find(qn('a:solidFill'))
    if solidFill is None:
        solidFill = etree.SubElement(chart_spPr, qn('a:solidFill'))
    srgbClr = solidFill.find(qn('a:srgbClr'))
    if srgbClr is None:
        srgbClr = etree.SubElement(solidFill, qn('a:srgbClr'))
    srgbClr.set('val', '<RRGGBB>')  # 如 'FFFFFF'

    # 方式3：设置背景透明度（0-100000，50000 = 50%）
    alpha = srgbClr.find(qn('a:alpha'))
    if alpha is None:
        alpha = etree.SubElement(srgbClr, qn('a:alpha'))
    alpha.set('val', '<透明度>')  # 如 '50000'

# 7. 设置绘图区域背景（图表内部数据区域）
plot_area = chart._element.find(qn('c:plotArea'))
if plot_area is not None:
    spPr = plot_area.find(qn('c:spPr'))
    if spPr is None:
        spPr = etree.SubElement(plot_area, qn('c:spPr'))

    # 透明绘图区（推荐）
    if spPr.find(qn('a:noFill')) is None:
        etree.SubElement(spPr, qn('a:noFill'))

    # 或设置绘图区填充色
    solidFill = spPr.find(qn('a:solidFill'))
    if solidFill is None:
        solidFill = etree.SubElement(spPr, qn('a:solidFill'))
    srgbClr = solidFill.find(qn('a:srgbClr'))
    if srgbClr is None:
        srgbClr = etree.SubElement(solidFill, qn('a:srgbClr'))
    srgbClr.set('val', '<RRGGBB>')
```

### 常用图表类型

| 图表类型 | XL_CHART_TYPE 常量 | 适用场景 |
|---------|-------------------|---------|
| 簇状柱状图 | XL_CHART_TYPE.COLUMN_CLUSTERED | 分类对比（如各年市场规模） |
| 堆叠柱状图 | XL_CHART_TYPE.COLUMN_STACKED | 多系列分类对比（如各行业占比） |
| 折线图 | XL_CHART_TYPE.LINE_MARKERS | 序列趋势（如用户增长曲线） |
| 面积图 | XL_CHART_TYPE.AREA | 趋势+占比（如市场份额变化） |
| 饼图 | XL_CHART_TYPE.PIE | 百分比占比（如行业分布） |
| 环形图 | XL_CHART_TYPE.DOUGHNUT | 百分比占比（比饼图更现代） |
| 条形图 | XL_CHART_TYPE.BAR_CLUSTERED | 排名对比（横向柱状图） |

### 图表样式与页面风格适配（极其重要）

**图表必须与页面的整体设计风格完全融合，不能看起来像是"嵌入了一个 Excel 截图"。**

### 图表布局原则
1. 图表位置和尺寸必须精确计算，确保不与标题、正文重叠
2. 图表宽度通常占页面的 50-70%，剩余空间放文字说明或指标卡片
3. 图表上下需留出足够间距（至少 0.3 英寸）
4. 如果页面有多个图表，使用水平排列而非垂直堆叠

### 严禁事项
- 严禁用 MSO_SHAPE.RECTANGLE 拼凑柱状图的柱体
- 严禁用 MSO_SHAPE.OVAL 拼凑饼图的扇区
- 严禁用折线（自由形状）手绘折线图
- 严禁用文本框标注坐标轴来模拟图表
- 如果 python-pptx 不支持某种特殊图表（如雷达图、漏斗图），改用表格或指标卡片展示数据
</chart_guidelines>

<layout_guidelines>
- 幻灯片标准尺寸为 13.333 x 7.5 英寸（宽屏 16:9）。
- 内容区域建议留边距：左右各 0.5-0.8 英寸，上下各 0.3-0.5 英寸。
- 标题区域高度约 0.8-1.0 英寸，位于页面上方。
- 正文区域从标题下方开始，高度约 5.5-6.0 英寸。
- 元素间距建议 0.4-0.6 英寸。

</layout_guidelines>

<visual_guidelines>
- 避免过度装饰，保持页面简洁专业。
- 使用设计规范中的配色，不要引入新颜色。
- 页面内的内容图片使用 add_picture 插入，路径直接硬编码为绝对路径字符串。
- **不要处理背景图**：背景图已由 set_background 函数统一设置，本函数只负责页面内容（标题、正文、内容图片、装饰形状等），不要重复设置背景。
- 不要使用 python-pptx 不支持的功能（如 CSS、HTML、SVG）。
- **图表页面必须使用 add_chart 创建原生图表**，不要用 shape 拼凑。
</visual_guidelines>
