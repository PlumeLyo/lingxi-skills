<anti_conflict_background_rules>

由于背景不会被后续内容生成阶段感知，必须满足：

1. **无强视觉中心**
   - 禁止在页面中心区域（约中间 60% 区域）放置任何高对比元素
   - 视觉重点应放在边缘（角落 / 边框区域）

2. **弱对比优先**
   - 背景与默认黑色/白色文字必须始终保持可读性
   - 避免高对比拼色（如纯黑+纯白块状对撞）

3. **低干扰装饰**
   - 所有装饰元素必须满足：
     - 面积小 或
     - 透明度视觉上较低（建议模拟 5%~15% 强度）
   - 禁止密集纹理 / 高频图案 / 强重复 pattern

4. **安全内容区（必须遵守）**
   - 默认假设内容主要分布在：
     - 中央区域
     - 左侧 60% 区域（常见文本布局）
   - 背景设计必须为这些区域“留白”或保持极低干扰

5. **避免语义干扰**
   - 禁止使用具体图标、插画、业务语义图形
   - 仅允许抽象元素（几何  / 线条）

6. **避免布局绑定**
   - 背景不得依赖具体标题位置、图表位置
   - 不得绘制“标题框”、“内容框”等强绑定结构

7. **装饰位置约束**
   - 推荐位置：
     - 左上角 / 右上角 / 右下角
   - 禁止：
     - 中央装饰
     - 横跨内容区的大块图形

</anti_conflict_background_rules>

<style_guidelines>

spPr = mask._element.spPr

srgbClr = solidFill.find(qn('a:srgbClr'))
if srgbClr is not None:
    alpha = etree.SubElement(srgbClr, qn('a:alpha'))
    alpha.set('val', '50000')  # 50% 不透明度

设置形状透明度（通用方法）：

from pptx.oxml.ns import qn

spPr = shape._element.spPr
solidFill = spPr.find(qn('a:solidFill'))
srgbClr = solidFill.find(qn('a:srgbClr'))
if srgbClr is not None:
    alpha = etree.SubElement(srgbClr, qn('a:alpha'))
    alpha.set('val', '15000')  # 15% 不透明度

透明度值说明：
- val 范围：0（完全透明）到 100000（完全不透明）
- 常用值：10000 (10%), 20000 (20%), 50000 (50%), 80000 (80%)
- 背景遮罩建议：30000-70000 之间

XML 操作常见错误总结：

shape.fill._fill 不是 XML Element，必须使用 shape._element.spPr
不要使用 .find() 查找 spPr，应直接访问 .spPr
修改透明度后如需改颜色，需重新调用 fill.solid()
必须先 fill.solid() 再设置透明度，否则 solidFill 不存在
需要 from lxml import etree 才能使用 SubElement
