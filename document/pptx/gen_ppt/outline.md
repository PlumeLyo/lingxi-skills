# 规划内容大纲，输出 `<ppt_outline>`

以"顶尖 PPT 内容专家与信息架构师"身份，将内容拆解为若干页面。

**页面角色规则：**

- 总页数 ≤ 3 页：跳过封面、目录、结尾，全为内容页
- 总页数 > 3 页：封面 → 目录 → 正文 → 结尾

**核心原则：**

1. 严禁编造数字、KPI、日期、人名、公司名等数据
2. 原文结构清晰时，优先按原文标题层级分页；逻辑模糊时按 SCQA 模型重构
3. 每页定义 1 个核心内容（观点性金句、关键行动逻辑或重要成果）
4. 禁止规划 emoji；禁止 CSS 动画和过渡效果

**内容大纲详细程度要求（硬性规则）：**

每页的 `<content>` 必须包含**可直接用于排版的完整文案**，而非抽象描述。具体要求：

- **标题**：明确写出页面标题文字
- **副标题/标语**：如有，写出具体文字
- **正文段落**：写出完整的段落文字，包含要点列表（用 `•` 标记）
- **数据/数字**：涉及数据展示时，写出具体数值和单位
- **标注/说明文字**：图表旁的注释、脚注等辅助文字也要写出
- **按钮/标签文字**：如有交互元素或标签，写出具体文字

> **反面示例（禁止）：** "介绍公司发展历程，展示三个关键里程碑"
> **正面示例（必须）：** "公司发展历程\n• 2018年 成立，首款产品上线\n• 2020年 用户突破100万\n• 2023年 完成B轮融资，估值10亿"

**可视化规划规范：**

**图表（`type="chart"`）**

| 数据类型       | 推荐图表                      |
| -------------- | ----------------------------- |
| 无数据/纯文字  | 禁止使用统计图表              |
| 1-2 个数值指标 | 大数字指标卡片（Metric Card） |
| 分类对比       | 柱状图 / 横向条形图           |
| 序列趋势       | 折线图 / 面积图               |
| 百分比占比     | 环形图                        |
| 多组多维数据   | 数据表格                      |
| 对比/转化逻辑  | 非对称双栏布局、对比表        |
| 过滤/提炼逻辑  | 价值漏斗                      |
| 演进/闭环逻辑  | 阶梯图、循环布局              |
| 结构/治理逻辑  | 架构堆叠图                    |

**图片（`type="image"`）**

| 适用场景                 | 说明                                              |
| ------------------------ | ------------------------------------------------- |
| 氛围图、场景图、主题配图 | 描述所需图片的内容，第 3 步据此生成               |
| 抽象概念视觉化           | 用隐喻、极简或概念性的画面表达抽象的商业/技术逻辑 |

> **生图原则：**
>
> 1. **非必要不生图**：仅在图片能显著提升表达力（如封面、愿景、情感渲染）时使用。如果只是为了填补空白，请优先使用排版留白或图表。
> 2. **拒绝过度具象**：对于抽象概念（如"战略"、"协同"、"赋能"），避免生成生硬的字面意思图片，应采用高级的隐喻、几何图形、光影或极简概念图。

**图标（`type="icon"`）**

图标是 PPT 中的重要视觉辅助元素，用于增强信息表达与视觉层次，但应克制使用，避免干扰内容本身。
原则：单页优先保证信息清晰，其次再考虑图标增强，不得滥用。
适用场景 使用规则
卡片/模块装饰图标 卡片数量较少（≤4个）时使用；若卡片较多，应避免全部配图标，防止视觉噪声
流程/步骤节点图标 优先使用；适用于流程、时间线等结构化内容
数据指标图标 可使用；但每页不超过2–3个指标图标

**图标规划要求：**

- 每个图标必须写明**搜索关键词**（英文，用于在 Iconify 中搜索）和**使用位置**
- 搜索关键词应简洁具体，如 `"shield"`, `"chart-line"`, `"rocket"`, `"users"`, `"gear"`
- 使用位置应描述图标在页面中的具体放置点，如 `"第一个卡片的标题旁"`, `"列表第二项的左侧"`, `"页面标题右侧"`
- 单页图标数量建议 1-6 个，不宜过多
- 图标颜色将在第 3 步根据 `<design_spec>` 中的配色自动设置

**`<visual_element>` 填写规则：**

| `type` 值 | 内容格式            | 说明                                                                                                                   |
| --------- | ------------------- | ---------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `chart`   | 自然语言描述        | 写明图表类型、展示的数据、放置位置；无真实数据时禁止使用                                                               |
| `image`   | 所需图片内容描述    | 描述该位置需要什么样的图片（主题、风格、意境、构图），需紧扣当页核心内容。第 3 步据此生成图片并记录在 `_images.xml` 中 |
| `icon`    | 图标搜索关键词+位置 | 格式：`搜索关键词                                                                                                      | 使用位置描述`。第 3 步据此搜索并下载图标，转换为 JPEG 后记录在 `\_images.xml` 中 |

> 每页可包含**零个或多个** `<visual_element>`；不需要可视元素时省略该标签。

> **禁止将背景图放入 `<visual_element>`**：背景图已在第 1 步 `<design_spec>` 的 `<background_images>` 中统一规划，此处只需规划页面内的内容图片（如配图、插图、图标等）。

** 页面布局速查:**

每张幻灯片精确分类为以下 5 种类型之一:

## 1. 封面页

**用途:** 开场 + 定调  
**内容:** 大标题、副标题/演讲者、日期/场合、强视觉背景/主题元素

### 布局选项

#### 非对称左右布局

- 文字集中在一侧,图像在另一侧
- **最适合:** 企业演示、产品发布、专业报告

```
|  标题 & 副标题    |    视觉/图像      |
|  描述信息         |                   |
```

#### 居中对齐布局

- 内容居中,带背景图
- **最适合:** 励志演讲、活动演示、创意提案

```
|                                        |
|           [背景图像]                   |
|              主标题                    |
|              副标题                    |
|                                        |
```

### 关键原则

- **戏剧化对比:** 主标题应至少比副标题大 2-3 倍
- **视觉锚点:** 最大的文本成为焦点
- **可读层级:** 观众应立即理解什么最重要
- **避免相似:** 相邻文本元素大小差异不得小于 20%

### 内容元素

- **主标题** — 始终必需,最大字体
- **副标题** — 需要额外上下文时使用(明显小于标题)
- **图标** — 当它们强化主题时使用
- **日期/活动信息** — 相关时使用(最小文本)
- **公司/品牌 Logo** — 代表组织时使用
- **演讲者姓名** — 用于主题演讲(小、低调)

---

## 2. 目录页

**用途:** 导航 + 设定预期(3-5 个章节)  
**内容:** 章节列表(可选图标/页码)

### 布局选项

#### 编号垂直列表

**最适合:** 3-5 个章节,直接的演示

```
|  目录                                  |
|                                        |
|  01  第一章节标题                      |
|  02  第二章节标题                      |
|  03  第三章节标题                      |
```

#### 双栏网格

**最适合:** 4-6 个章节,内容丰富的演示

```
|  目录                                  |
|                                        |
|  01  第一章节    02  第二章节          |
|      描述            描述              |
|  03  第三章节    04  第四章节          |
```

#### 侧边栏导航

**最适合:** 3-5 个章节,现代/企业风格

```
| ▌01 |  第一章节标题                      |
| ▌02 |  第二章节标题                      |
| ▌03 |  第三章节标题                      |
```

#### 卡片式

**最适合:** 3-4 个章节,创意/现代风格

```
|  目录                                    |
|  ┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐    |
|  │ 01  │  │ 02  │  │ 03  │  │ 04  │    |
|  │标题 │  │标题 │  │标题 │  │标题 │    |
|  └─────┘  └─────┘  └─────┘  └─────┘    |
```

### 关键原则

- **清晰编号:** 章节编号应在视觉上突出 — 粗体、强调色或更大尺寸
- **可扫描结构:** 观众应在 2-3 秒内扫完所有章节
- **一致间距:** 章节之间垂直间距相等
- **视觉标记:** 彩色圆点、线条、数字或图标来锚定每个章节
- **避免杂乱:** 描述最多一行或完全省略

### 内容元素

- **页面标题** — 始终必需("目录"、"议程"、"概述")
- **章节编号** — 一致格式(01, 02... 或 I, II...)
- **章节标题** — 清晰简洁
- **章节描述** — 可选的单行摘要
- **视觉分隔符** —分隔线或间距
- **装饰元素** — 细微的强调形状

---

## 3. 章节页

**用途:** 主要部分之间的清晰过渡  
**内容:** 章节编号 + 标题(+ 可选 1-2 行引言)

### 布局选项

#### 粗体居中

**最适合:** 极简、现代演示

```
|                  02                    |
|           章节标题                     |
|         可选引言文字                   |
```

#### 左对齐带强调块

**最适合:** 企业、结构化演示

```
| ████ |  02                            |
| ████ |  章节标题                      |
| ████ |  可选引言文字                  |
```

#### 分割背景

**最适合:** 高对比度、戏剧化过渡

```
| ██████████ |     章节标题              |
| ██  02  ██ |     可选引言              |
| ██████████ |                           |
```

#### 全出血背景带叠加层

**最适合:** 创意、大胆演示

```
| ████████████████████████████████████  |
| ████       大号 02        ██████████ |
| ████    章节标题          ██████████ |
| ████████████████████████████████████  |
```

### 关键原则

- **戏剧化数字:** 章节编号 = 最突出的视觉元素
- **强标题:** 大但明显次于编号
- **最小内容:** 仅编号 + 标题 + 可选单行
- **留白:** 留出充足空白 — 分隔页是暂停时刻

### 内容元素

- **章节标题** — 始终必需。清晰、简洁
- **引言文本** — 可选 1-2 行描述
- **装饰元素** — 强调形状(条、线、几何块)

---

## 4. 内容页

#### 文本型 (Text)

项目符号、引用或短段落

**必须**仍包含图标或形状 — 绝不纯文本

```
|  幻灯片标题                            |
|  * 要点一                              |
|  * 要点二                              |
|  * 要点三                              |
```

#### 混合媒体 (Mixed Media)

双栏或半出血图像 + 文本

```
|  幻灯片标题                            |
|  文本内容         |  [图像/视觉]       |
|  和要点           |                    |
```

#### 数据可视化 (Data Visualization)

图表(条形/进度/环形) + 要点

**必须**包含数据源

```
|  幻灯片标题                            |
|  [图表]       |  关键要点 1        |
|                   |  关键要点 2        |
|                   数据来源: xxx        |
```

#### 对比 (Comparison)

并排栏或卡片(A vs B、优缺点)

```
|  幻灯片标题                            |
|  ┌─ 选项 A ─┐    ┌─ 选项 B ─┐        |
|  │  详情 1  │    │  详情 1  │        |
|  └───────────┘    └───────────┘        |
```

#### 时间轴/流程 (Timeline / Process)

带箭头的步骤、旅程、阶段

```
|  幻灯片标题                            |
|  [1] ──→ [2] ──→ [3] ──→ [4]         |
|  步骤    步骤    步骤    步骤          |
```

#### 图像展示 (Image Showcase)

英雄图像、画廊、视觉优先布局

```
|  幻灯片标题                            |
|  ┌────────────────────────────────┐   |
|  │         [英雄图像]             │   |
|  └────────────────────────────────┘   |
|  说明文字或支持文本                    |
```

### 关键原则

- **左对齐正文** — 绝不居中段落或项目符号列表
- **尺寸对比** — 标题必须 36pt+ 才能从 14-16pt 正文中突出
- **必需视觉元素** — 每张内容页必须至少有一个非文本元素
- **留白** — 最小 0.5" 边距,内容块之间 0.3-0.5"

### 内容元素

- **幻灯片标题** — 始终必需,幻灯片顶部
- **主体内容** — 基于子类型的文本、要点、数据或对比
- **视觉元素** — 图像、图表、图标或 形状 — 始终必需
- **来源/标注** — 显示数据或外部内容时使用

---

## 5. 结束页

**用途:** 总结 + 行动  
**内容:** 关键要点、CTA/后续步骤、联系方式/二维码、致谢

### 布局选项

#### 关键要点

**最适合:** 教育、企业、数据驱动演示

```
|  关键要点                              |
|  ✓  要点一                             |
|  ✓  要点二                             |
|  ✓  要点三                             |
```

#### CTA / 后续步骤

**最适合:** 销售宣传、提案、项目启动

```
|  后续步骤                              |
|  [1] 行动项一                          |
|  [2] 行动项二                          |
|  联系方式: email@example.com           |
```

#### 致谢/联系方式

**最适合:** 会议演讲、主题演讲

```
|            感谢聆听                     |
|         name@company.com               |
|         @handle | website.com          |
```

#### 分割回顾

**最适合:** 需要回顾和行动的演示

```
|  总结                |  后续步骤         |
|  * 要点一            |  联系我们         |
|  * 要点二            |  email@co.com     |
|  * 要点三            |  [二维码]         |
```

### 关键原则

- **强结束陈述:** 主要信息应最大、最突出
- **可扫描项:** 要点/行动项简洁(每项一行)
- **联系清晰:** 清晰易读但不突兀
- **令人难忘的结尾:** 自信、优雅的结束

### 内容元素

- **结束标题** — 始终必需
- **要点** — 3-5 个简洁总结点(如适用)
- **行动号召** — 清晰的后续步骤(如适用)
- **联系信息** — 邮箱、网站、社交账号(如提供)
- **装饰元素** — 强调元素保持视觉一致性

---

## 附加布局模式

在内容页中使用这些模式增加视觉多样性:

- **双栏**(左文本,右插图)
- **图标 + 文本行**(彩色圆圈中的图标,粗体标题,下方描述)
- **2x2 或 2x3 网格**(一侧图像,另一侧内容块网格)
- **半出血图像**(完整左侧或右侧)带内容叠加
- **大号统计数据突出**(60-72pt 大数字,下方小标签)
- **对比栏**(前后对比、优缺点)
- **时间轴或流程**(编号步骤、箭头)
- **小彩色圆圈中的图标**位于章节标题旁
- **关键统计数据或标语的斜体强调文本**

调用 `start_write_file(path="{pptdir}/outline.xml")` 开启写作模式，直接输出以下 XML 内容，输出完毕后调用 `end_write_file()` 保存：

```xml
<ppt_outline>
<page number="1">
<role>封面页</role>
<title>演示文稿标题</title>
<content>
该页要传达的核心信息，包括标题、副标题、各区块文案（必须写出完整可排版的文案，而非抽象描述）
</content>
<layout>参考布局选项给出布局方案</layout>
<visual_element type="chart">描述图表具体内容</visual_element>
<visual_element type="image">描述图片内容</visual_element>
<visual_element type="icon">搜索关键词 | 使用位置描述</visual_element>
</page>
<!-- 更多页面... -->
</ppt_outline>
```

**本步产出物：** `{pptdir}/outline.xml`

** type说明: ** type用来区分页面类型， 目前支持的页面类型仅有["封面页", "目录页", "章节页", "内容页", "结尾页"]
