# 战略规划

> 适用场景：项目提案、商业计划书、融资路演、创业大赛、投资提案、战略规划报告等
> 风格锚点：顶级咨询公司战略报告 + YC/红杉资本推荐的路演风格 + Airbnb/Uber 等经典融资演示

## 设计理念

- **宏大愿景，宏观视角**：从行业趋势和大格局出发，构建宏大的叙事框架，向受众传递战略高度和格局
- **清晰故事线**：用决策者熟悉的叙事框架（背景/痛点 → 目标 → 路径 → 预期收益 → 保障机制）讲述完整的战略故事
- **重点突出**：每页一个核心论点；快速浏览即可了解整体战略图景
- **数据说服力**：关键商业数据（市场规模、增长率、ROI、预期收益）必须突出且可信，所有结论有数据支撑
- **高级感与克制**：专业、稳重、大气，在权威感与现代感之间取得平衡；避免所有廉价或华丽的设计元素
- **收益导向**：每个规划步骤都明确关联预期产出，使决策者能清晰看到投入与产出的因果关系

## 信息密度：中等至高

- 内容区域填充率 **65-85%**，整体密度高于普通演示文稿
- 每页聚焦**一个核心论点**，但允许更丰富的数据和图表进行充分论证
- 核心数据页（市场规模、财务预测、ROI 分析）偏向高密度，至少包含 3 个大数字 + 1 张图表 + 3 条要点说明
- 战略愿景页和总结页使用适中密度，保留适当留白以传达高级感
- 路径规划页和方案对比页允许高密度布局，通过卡片、表格、时间轴等进行结构化呈现
- 每页 4-6 个关键信息点；核心论证页可达 7 个

> **原则：在 10 分钟内翻阅完所有幻灯片后，决策者能清晰回忆起战略目标、执行路径和预期收益**

### 密度参考

中高密度内容页的典型构成（1280×720 画布）：数据页基准要求 3 个大数字 + 1 张图表 + 3 条要点说明——不能低于此数量；路径规划页至少需要时间轴/流程图 + 阶段目标 + 关键里程碑；战略愿景页至少需要标题 + 3-4 条要点 + 支撑图片或图标——页面不能只有标题和几行文字。

## 图文比例：均衡，数据偏重

- 内容页推荐比例：约 45% 文字/数据 + 35% 图表 + 20% 图片/图标
- 市场分析和财务页以图表为主（柱状图、折线图、饼图、组合图）；pptd.md 中未定义的常见图表类型（如瀑布图）可以用形状 + 文本框组合构建
- 路径规划页使用时间轴、流程图等结构化图形
- 产品页和团队页使用图片（产品截图、团队照片）
- 图标辅助商业模式、竞争优势和战略框架的说明

## 配色指导

- **稳重、高级、有力量的配色方案**，传递战略远见和专业权威
- 推荐主色调：低饱和深色调，如深海蓝、海军蓝、深绿色，搭配白色、中性灰、米色
- 如果存在品牌色，围绕品牌色构建色彩系统，同时保持整体稳重的基调
- 深色页面：深色背景 + 白色文字 + 主题色强调
- 浅色页面：白色或浅色背景 + 深色文字 + 主色用于标题和强调
- 强调色：一种对比色用于关键数字、增长指标、行动按钮等；金色或琥珀色可传递高级感
- **严禁**：高饱和荧光色、过多颜色（>3种主色）、对撞配色组合

## 字体指导

- **标题**：无衬线加粗（例如 QuattrocentoSans Bold / Liter Bold），有力、权威、现代
- **正文**：无衬线常规，清晰可读，适中行距
- **大数字**：无衬线加粗或细体（超大字号下细体有更多呼吸空间和高级感）
- 字号层级：封面标题 40-56px → 页面标题 28-34px → 正文 18-22px（文字少时用 22px，适中时用 20px，较多时用 18px；不得低于 18px）→ 注释 12-16px
- 大数字展示：44-60px，搭配小字号的解释性文字
- 标题措辞应精炼有力，体现战略高度

## 内容页

- 推荐结构：**页面标题（顶部）→ 核心内容 → 底部注释/页码**
- 页面标题直击要点——是核心论点，而非章节名称（错误："市场分析"；正确："全球 SaaS 市场 2000 亿美元，中国渗透率仅 10%，3 年窗口期"）
- 常见布局：
  - **居中大数字**：用于市场规模、ROI、核心 KPI 展示
  - **左右分栏**：图表 + 文字解读，或现状 + 目标对比
  - **三/四栏卡片**：方案对比、竞争分析、阶段目标
  - **时间轴/路线图**：战略路径、里程碑规划
  - **目标-路径-收益框架**：顶部战略目标，中部执行路径，底部量化预期收益
- 建议使用文字样式构建信息分组；必要时使用矩形卡片和图标补充信息分组
- 关键页面（市场规模、牵引力、财务预测、ROI）可使用深色背景以示强调

## 叙事风格：说服驱动

- **战略规划叙事框架**：背景与趋势 → 问题与机遇 → 战略目标 → 执行路径 → 资源需求 → 预期收益与ROI → 风险与保障 → 总结与行动号召
- **融资叙事框架**：问题 → 解决方案 → 产品 → 市场规模 → 商业模式 → 竞争优势 → 牵引力 → 团队 → 财务预测 → 融资需求
- 两个框架可根据场景灵活选择或融合
- 每页标题是核心论点，而非章节名称（错误："融资计划"；正确："本轮融资 5000 万，18 个月实现盈亏平衡"）
- 前半部分建立需求和机遇（为什么要做）；后半部分展示能力和收益（怎么做，能得到什么）
- **预期收益必须明确陈述**：每个战略举措都必须明确关联量化收益，使决策者能看到投入产出比
- 语言自信、有力、克制——不夸张但敢于表态；数据有来源
- **数据来源注释**：引用市场数据或行业报告时，应附来源注释（例如 `来源：机构名称，年份`），使用 `<a href="url">` 超链接指向原始报告或数据页面，增强可验证性

## 内容表达技巧

- **TAM/SAM/SOM**：市场规模用嵌套圆、瀑布图（pptd.md 中未定义，可用形状 + 文本框组合构建）或大数字 + 层级展示可视化
- **增长曲线**：牵引力数据用折线图展示增长趋势，标注关键里程碑
- **单位经济模型**：大数字 + 公式拆解（CAC、LTV、毛利率等）
- **竞争矩阵**：二维矩阵图定位竞争格局，突出自身优势位置
- **目标-路径-收益链**：流程图或三段式结构清晰展示"做什么 → 怎么做 → 能得到什么"
- **ROI 分析**：投入产出比突出展示为大数字，辅以成本分解和收益预测图表
- **里程碑路线图**：时间轴展示关键节点，每个节点标注阶段目标和预期产出
- **风险矩阵**：二维矩阵（概率×影响）展示风险分布，配以缓解策略
- **团队展示**：照片 + 姓名 + 背景（一行），突出核心团队的行业经验和战略执行能力
- **融资计划**：清晰的金额、分配比例（饼图适用）、关键里程碑时间线
- **客户 Logo 墙**：现有客户/合作伙伴的 Logo 展示，增强可信度

## 装饰禁忌

| 禁忌 | 替代方案 |
|--------|---------|
| 大段文字段落 | 提炼为要点列表和数据 |
| 无数据支撑的断言 | 附具体数字和来源 |
| 过于华丽的视觉装饰 | 简洁、稳重的静态展示 |
| 通用图库照片 | 真实产品截图或高质量品牌图片 |
| 信息过载（>7个要点/页） | 分页；每页一个焦点 |
| 模糊的竞争分析 | 具体指标对比矩阵或表格 |
| 收益仅做定性描述 | 量化收益数字（ROI、增长率、节省成本） |
| 数据堆砌无结论 | 三段式：数据 + 洞察 + 行动建议 |
| 低质量渐变和阴影 | 纯色或非常微妙的渐变，保持高级感 |
| 圆角矩形 | 除非必要，否则优先使用直角矩形或无边框布局，传递战略报告的严谨性和权威性 |
