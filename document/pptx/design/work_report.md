# 工作报告 / 绩效考核

> 适用场景：工作报告、项目总结、绩效考核、季度/年度述职、政府/党政风格报告、绩效答辩演示等
> 风格锚点：企业内部管理报告，强调组织清晰、数据丰富、结论先行、事实驱动的叙事

## 设计理念

- **结论先行**：每页以结论和结果开头，然后再阐述过程和细节；领导层应能在 3 秒内抓取核心信息
- **事实驱动**：数据、事实和客观成果构成叙事骨架；避免主观感受和模糊修辞
- **组织清晰**：模块化结构，每页一个主题，逻辑链条清晰可追溯
- **务实简洁**：不追求视觉炫技；信息传达清晰是首要优先级，装饰从属于内容
- **数据可视化优先**：能用图表就不用文字；能用 SmartArt 就不用纯列表

## 信息密度：中高（70-80%）

- 每页聚焦一个清晰主题，内容区域填充率 70-80%
- 关键成果数据以大数字（34px+）展示，附简短的对比注释（同比/环比/完成率）
- 使用列表和表格组织信息；每组要点 3-5 条；避免长段落
- 适当留白以获得呼吸感，但避免大面积空白
- 基准要求：页眉导航 + 结论式标题 + 2-3 个 KPI 大数字 + 4-5 条成果要点 + 至少 1 张图表或 SmartArt + 下一步计划

> **原则：领导层翻阅时，能在 3 秒内掌握每页的核心信息；深度阅读时，能找到支撑数据和细节**

## 图文比例：文字主导，图表辅助

- 内容页推荐比例：约 60% 文字/表格 + 30% 图表/SmartArt + 10% 图标/装饰
- 数据成果页必须包含图表可视化（柱状图、折线图、饼图等）；仅列数字不可接受
- 流程/机制/组织架构页应优先使用 SmartArt（流程图、层级图、循环图、关系图）而非纯文字列表
- 时间轴和里程碑页使用形状+文字的时间轴布局
- 减少照片使用；专注于信息图表和数据图表；禁止纯装饰性图片

### SmartArt 使用建议

SmartArt 在 PPTD 中通过形状 + 文字 + 线条组合实现。SmartArt 是提升工作报告信息表达的核心工具，应积极使用：

- **流程图**：适合工作进展流程、审批流程、项目阶段展示（例如，"需求分析 - 方案设计 - 实施部署 - 验收交付"）
- **层级图**：适合组织架构、汇报关系、管理体系展示
- **循环图**：适合闭环管理机制、PDCA 循环、持续改进流程
- **关系图**：适合部门协作关系、利益相关者分析、SWOT 分析、核心竞争力模型等多维关系展示
- **矩阵图**：适合优先级排序、风险评估（影响/概率矩阵）、SWOT 分析
- **漏斗图**：适合销售转化、客户筛选、流程收敛等场景
  * pptd.md 中未定义的常见图表类型（如瀑布图）可以用形状 + 文本框组合构建

> **原则：任何能够结构化的信息，优先用 SmartArt 呈现，减少纯文字堆砌**

### 数据图表使用建议

图表是量化成果表达的最佳工具，应广泛使用：

- **柱状图/条形图**：对比数据（计划 vs 实际、部门对比、季度对比）
- **折线图**：趋势数据（月度/季度趋势、增长曲线）
- **饼图/环形图**：构成数据（营收结构、预算分配、问题类别占比）
- **组合图**（柱状图 + 折线图）：同时展示绝对值和变化率
- **堆积柱状图**：展示总量及其内部构成变化
- 每张图表必须有清晰的标题、数据标签和图例，确保无需口头解释即可理解

## 配色指导

### 通用企业场景

- **稳重、专业的配色方案**，传递专业性和可信度；避免过于活泼或休闲的配色倾向
- 如果内容涉及品牌，优先使用品牌色；可通过搜索确认品牌色
- 清晰的颜色层级：背景、正文、标题和强调色应有明显的视觉层级；避免主次不分
- 强调色应克制使用，仅用于数据高亮和重点标注，作为视觉焦点
- **严禁**：过于鲜艳的多色组合、渐变滥用、荧光色

### 国有企业/政府党政场景

- 以企业品牌/主题色（国有企业）或中国红、党旗红（政府/党政场景）为核心构建主色系；金色可作为强调色
- 封面/章节页可使用红色渐变或大面积红色色块；内容页应保持白色/浅灰色背景以确保可读性
- 标题和关键数据用红色或金色突出；正文保持深灰/黑色
- 党徽、国徽等政治符号仅在明确需要时使用，放置在封面或固定装饰位置；不得随意散布
- 整体基调应庄重大气；避免花哨

## 字体指导

- **标题**：无衬线加粗（例如 MiSans Bold），简洁有力
- **正文**：无衬线常规（例如 MiSans），确保屏幕可读性
- 字号层级：封面标题 40-52px - 页面标题 26-32px - 副标题 22-26px - 正文 18-22px（文字少时用 22px，适中时用 20px，较多时用 18px；不得低于 18px）- 导航 16-18px - 脚注 12-16px
- KPI 大数字 38px，使用强调色以突显
- 全程使用无衬线体；不需要衬线/无衬线对比
- 国有企业场景下，标题可选用 siyuanSongti、alimamadongfangdakai 等政务风格字体

## 内容页

内容页可使用以下元素，但均非强制：
- **导航栏**：建议设置与页面宽度/高度匹配的水平或垂直导航栏，章节标题均匀分布，当前章节用带主题边框的白色矩形和可读文字颜色突出显示，帮助受众跟踪演示进度和整体结构
- **页面标题**：结论式成果句（一行），概括该页的核心成果，而非泛泛的主题词
- **公司 logo**：当用户指定公司名称时，建议在线搜索公司 logo（或从用户上传的附件中提取）并放置在每页统一的固定位置，清晰标明汇报单位
- 可采用**导航栏 - 主标题 - 分隔线 - 图表/SmartArt - KPI 大数字+成果要点 - 报告信息/页码**的标准结构，但这只是一种可能的结构，并非强制
- **内容区域**常用元素：
  - 图表/SmartArt，快速将复杂信息结构化为易消化的内容
  - KPI 大数字，突出重要信息
  - 中等长度句子的成果要点，解释核心观点和内容，既不过简也不过长

### 绩效答辩场景特殊要求

绩效答辩演示与普通工作报告不同，需要特别注意：

- **个人简介页**：开篇应包含基本个人信息、岗位职责和任期信息，呈现简洁
- **自我评价应客观量化**：用数据支撑能力评价；避免"勤奋负责"、"积极主动"等空洞措辞
- **清晰的对标维度**：系统性回答每个维度——岗位 KPI、职责履行、创新突破、团队贡献
- **成长与不足并存**：建议包含"不足与改进"部分以展示自我认知，但占总内容不超过 15%
- **明确的未来计划**：下一步计划应关联岗位目标，明确量化目标和时间节点
- **推荐答辩结构**：个人介绍 - 岗位职责 - 工作成果（按维度展开）- 亮点与创新 - 不足与改进 - 未来规划

### 国有企业汇报场景特殊要求

- **政治定位优先**：第一页或第一章应体现政策背景、上级指示和战略部署落实情况
- **规范化汇报语言**：使用正式表述，如"在……指导下"、"认真贯彻……"、"稳步推进……"、"取得显著成效"等；避免口语化表达
- **数据严谨**：所有数据必须可追溯；财务数据必须说明依据（如含税/不含税、合并/单体）；外部行业或基准数据引用应使用 `<a href="url">` 超链接注明来源
- **对标对齐**：工作成果必须与上级下达的年度目标和考核指标逐项对比，使用对比表或完成率图表
- **党建融合**：如涉及党建工作，应单独列章，体现"党建引领业务"的逻辑
- **规范章节命名**：建议使用"工作回顾"、"主要成果"、"经验与最佳实践"、"存在问题"、"下一步计划"等标准章节名称

## 叙事风格：成果汇报

- 每页标题概括核心结论或成果（例如，"Q3 销售收入同比增长 23%，超额完成目标"）；严禁没有信息价值的泛泛标题如"工作成果"
- 内容按**成果 - 过程 - 下一步**逻辑组织
- 用数据说话：凡能量化的成果，尽量用数字表达；避免模糊的定性描述（例如，用"提升了 23%"代替"显著提升"）
- 问题与挑战部分必须包含解决方案或行动计划；呈现问题而无解决方案不可接受
- 避免过度谦虚或过度自我宣传；保持客观语气

## 内容表达技巧

- **KPI 大数字**：核心成果指标以大数字 + 对比基准（同比/环比/完成率/行业均值）展示，给数字提供参考框架
- **进度条/完成率**：使用形状模拟进度条，直观展示目标完成情况；标注百分比值
- **时间轴**：项目里程碑和工作进展节奏使用时间轴 SmartArt 或形状组合布局展示
- **对比表格**：计划 vs 实际、本期 vs 上期、目标 vs 已完成——清晰的表格对比，标注达成率
- **要点列表**：每条要点以加粗关键词开头，后接具体数据和量化结果
- **下一步**：清晰的行动项 + 负责人 + 时间节点；建议使用表格或 SmartArt 呈现
- **SmartArt 流程/关系图**：工作流程、组织关系、管理机制等结构化信息优先图形化表达
- **数据图表**：趋势、对比和构成数据必须使用图表；纯文字描述不可接受

## 装饰禁忌

| 禁忌 | 替代方案 |
|--------|---------|
| 大型装饰性图片 | 数据图表和 SmartArt |
| 颜色过多（>4种） | 主色+次要色+强调色，三色为主 |
| 艺术字/文字特效 | 标准字体加粗即可 |
| 无意义的图标过载 | 仅在需要视觉区分时使用图标 |
| 过度视觉效果 | 简洁克制的静态展示 |
| 纯装饰性背景图案 | 纯色或极浅纹理 |
| 空洞的定性描述 | 量化数据 + 图表佐证 |
| 圆角矩形 | 优先使用直角矩形或无边框布局，保持务实简洁的商务风格 |
