# 通用

> 适用场景：不明确符合其他专项类别的通用演示场景，如会议分享、项目介绍、工作沟通、内部讨论等
> 风格锚点：专业、清晰、适度精致的通用商务风格

## 设计理念

- **内容丰富**：页面不能空洞；每页应有实质性内容，避免大面积留白或信息稀疏
- **专业克制**：既不过度装饰，也不过于朴素，保持适当的美感和专业性
- **结构清晰**：逻辑层级分明，信息组织有序，使读者能快速抓取要点
- **视觉丰富**：善用图表和 SmartArt 辅助信息传达，避免纯文字墙

## 信息密度：中高

- 内容区域填充率 **65-80%**，页面看起来充实但不拥挤
- 每页承载一个完整主题，围绕该主题提供充分的论据和数据支撑
- 鼓励图表+文字组合在单页呈现多层次信息
- 避免单张大图占满整页或仅 2-3 条要点的稀疏页面

> **原则：读完一页后，读者应该感觉"信息完整，表达清晰"——既不空洞，也不冗长**

## 图文比例：均衡

- 内容页推荐比例：约 **50% 文字** + **35% 图表/SmartArt** + **15% 留白**
- 鼓励使用图表（柱状图、折线图、饼图等）将数据可视化，呈现更直观
- 鼓励使用 SmartArt 表达流程、关系、层级等逻辑结构
- 避免纯文字页面——如果某页只有文字，考虑是否可以将部分内容替换为图表或 SmartArt

## 配色指导

- 如果用户提供了品牌色，优先使用品牌色
- 推荐**三色体系**：主色 + 灰度 + 一种强调色，保持视觉一致性
- 以浅色调为主；对于科技等特殊主题，可使用场景适合的深色方案 + 白色文字
- 严禁过于花哨的多色组合；全文不超过 4 种颜色（包括灰度）

## 字体指导

- 标题：无衬线加粗，确保视觉层级突出
- 正文：无衬线常规，保持阅读舒适度
- 字号层级：封面标题 **40-52px** → 页面标题 **26-32px** → 副标题 **22-26px** → 正文 **18-22px**（文字少时用 22px，适中时用 20px，较多时用 18px；不得低于 18px）→ 脚注 **12-16px**

## 内容页

- 推荐布局：**页面标题**（顶部）→ **细灰色分隔线** → **自由内容区域** → **页码**（右下角）
- 页面标题应是该页核心点的概括句；读标题即传达该页主要信息
- 适度使用 SmartArt 构建流程图、关系图和层级图

## 叙事风格：逻辑清晰

- 每页标题概括核心要点，而非简单的主题词
- 信息按逻辑层级组织：一般 → 具体，原因 → 结果，问题 → 解决方案
- 语言简洁专业，以数据为驱动，避免模糊描述
- 关键结论和数据加粗，方便快速浏览

## 内容表达技巧

- **图表**：柱状图、折线图、饼图等数据可视化，使数据更有说服力
- **SmartArt**：流程图、层级图、循环图，表达逻辑关系，比纯文字更直观（SmartArt 在 PPTD 中通过形状+文字+线条组合实现）
- **表格**：多维对比、数据汇总，适合结构化信息展示
- **KPI 大数字**：关键指标突出展示，吸引注意力
- **结构化列表**：每组要点 3-5 条，包含具体数据而非模糊描述
- **强调标注**：关键数据和结论加粗，方便读者快速提取

## 装饰禁忌

| 禁忌 | 替代方案 |
|--------|---------|
| 过度装饰/华丽效果 | 简洁、专业的视觉设计 |
| 大面积留白 | 充实的内容填充 |
| 纯文字页面 | 图表或 SmartArt 配合的图文组合 |
| 颜色过多（>4种） | 三色体系：主色+灰度+强调色 |
| 装饰性图标过载 | 仅在辅助理解时使用图标 |
| 渐变和阴影滥用 | 扁平纯色为主要方式 |
| 圆角矩形 | 除非用户有特殊要求，否则优先使用直角矩形或简洁的几何分割，保持专业克制的视觉风格 |
