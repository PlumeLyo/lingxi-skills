# 推广与营销

> 适用场景：品牌发布、营销活动、艺术/时尚/文化展示、产品介绍等
> 风格锚点：Apple 发布会 / 小米产品发布 / 高端时尚品牌 / 艺术展览 / 文化推广 / 高端品牌视觉系统

## 设计理念

- **顶级视觉冲击力**：大图片和大胆排版，用极致的视觉张力传递品牌调性、艺术质感或文化深度——每页都应让观众屏住呼吸
- **少即是多**：每页只传达一个核心信息，通过慷慨的留白和极简排版营造高级感；克制是最高的表达
- **情感驱动**：通过颜色、图像和文案激发情感共鸣，而非堆砌功能规格或信息条目
- **品牌/主题一致性**：每页都是品牌形象或主题身份的延伸；颜色、排版和基调高度统一，形成完整的视觉叙事
- **大胆布局**：打破常规网格；善用不对称构图、出血图片、超大排版、极致留白等技法，营造前卫、设计感强的效果

## 信息密度：低

- 每页只传达**一个核心信息**，内容区域填充率 **40-60%**
- 慷慨的留白是刻意的设计选择，而非内容不足
- 关键数字、标语和核心概念使用超大字体独占整页，赋予仪式感
- 字越少，每个字的分量越重；文案必须精雕细琢

## 图文比例：图片与视觉主导

- 内容页推荐比例：约 30% 文字 + 10% 图表 + 60% 图片/视觉元素
- 大量使用高质量图片：产品照片、场景照片、艺术摄影、文化素材、时尚大片等
- 文案应精炼，标语式表达，拒绝冗长段落
- 艺术/文化场景可使用艺术品图片、展览照片、纹理/材质图片替代常规素材

## 配色指导

- **颜色即调性**：颜色是传递品牌标识和情感氛围的主要语言
- 品牌发布：围绕品牌色构建；推荐品牌主色 + 黑/白 + 一种强调色
- 时尚/艺术场景：高饱和对撞色、莫兰迪调色板、单色调明暗渐变等大胆配色均可接受
- 文化推广：从主题文化意象中提取颜色（例如，水墨灰、故宫红、敦煌金）
- 允许在品牌或主题色系内的微妙渐变，以增强氛围深度

## 字体指导

- **排版是设计感的核心载体**；选择具有高级美感的字体至关重要
- 标题/标语：无衬线加粗或细体，超大字号（40-68px），追求视觉冲击力
- 艺术/文化场景的标题可使用衬线或书法字体，强化主题身份
- 正文：无衬线细体/常规，适中字号（18-22px；文字少时用 22px，适中时用 20px；不得低于 18px），保持优雅克制
- 用字重对比（Bold vs Light）代替字号对比，层级更为精致
- 字距和行距必须精心调校；慷慨的间距比紧密排列更显高级

## 内容页

- **居中标语页**：单句话以超大字体占满整个屏幕，营造仪式感
- **全出血图片 + 叠加文字**：图片填满整页；文字通过半透明叠加或直接叠加呈现
- **数据 KPI 卡片页**：大数字 + 极简注释；数字本身是视觉主角
- **左右分割/不对称布局**：一侧大图，一侧文字；比例可以大胆偏斜（例如 70:30）
- **纯色/渐变背景 + 单行文案**：极简主义极致化，仅靠颜色和排版承载
- 每页只承载一条信息；无固定标题栏，无页码，无导航元素
- 鼓励打破常规：尝试出血布局、对角切割、圆形裁切等非标准构图

## 叙事风格：故事与情感驱动

- 一条品牌故事线或主题线索贯穿整个演示文稿，具有清晰的情感节奏（铺垫、高潮、余韵）
- 文案精炼有力，标语式表达；每句话都值得被记住
- 情感语言和理性数据交替出现；情感打动人心，理性建立信任
- 艺术/文化场景可融入诗意表达和隐喻修辞，提升文案质量
- 避免说教式语气；让视觉和文字让观众自己感受

## 内容表达技巧

- **环境光效果**（核心技法）：超宽椭圆加径向渐变，营造舞台级光影氛围
- **日食效果**：圆形光晕/遮罩，营造神秘感和仪式感
- **KPI 数据卡**：大数字独立成组，通过字号和字重产生视觉冲击
- **标语表达**：核心文案超大字体居中显示；一句话定调
- **弧形地平线**：底部弧形分割，增加空间深度和优雅感
- **主讲人封面**：人物图片 + 品牌信息，建立个人/品牌连接
- **出血图片**：图片延伸超出页面边缘，打破框架约束
- **遮罩叠加**：半透明色块叠加在图片上，保留图片质感的同时确保文字可读性
- **纹理与材质**：在纯色背景上叠加细微纹理（纸张、织物、金属），增加触感深度

## 装饰禁忌

| 禁忌 | 替代方案 |
|--------|---------|
| 密集文字段落 | 提炼为短句或标语 |
| 复杂数据表格 | 大数字 + 极简图表 |
| 低质量/有水印图片 | 高质量品牌素材或艺术摄影 |
| 通用剪贴画 | 品牌定制视觉素材或高质量图标 |
| 单页信息过多 | 拆分为多页，每页一个焦点 |
| 企业模板感/通用外观 | 强化品牌或主题的独特视觉语言 |
| 廉价渐变/华丽效果 | 克制的高级渐变或纯色 |
| 字号过小和布局拥挤 | 大字号、宽间距、充足留白 |
| 风格混杂不统一 | 全程高度统一的视觉语言 |
| 圆角矩形 | 除非与特定品牌视觉系统强相关，否则优先使用直角或无边框布局，保持极简高级感 |
