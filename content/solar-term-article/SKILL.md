# 节气文案生成技能

本技能用于生成高质量节气主题公众号文案，融合节气知识、心理学洞察与人文表达。

## 核心工作流

### 1. 节气识别
- 检查当前日期，识别最近的节气（未来3天内）
- 参考 `references/solar_terms_2026.md` 获取节气日期、三候等基础信息

### 2. 内容框架构建
基于以下模块构建文章框架（根据内容丰富度选择性使用，无内容板块不生成）：
- **开篇**：节气日期、时间、个人化引入
- **三候**：节气物候特征，用生活化语言描述
- **心理主题**：参考 `references/psychology_themes.md` 获取对应心理主题
- **习俗养生**：节气相关传统习俗、养生建议
- **诗词解读**：1-2首节气诗词的现代解读
- **彳亍时刻**：个人叙事或生活观察
- **互动**：引导读者分享的问题
- **结语**：总结升华，呼应主题

### 3. 标题生成
参考 `references/title_strategies.md` 中的5种标题策略，轮换使用：
1. 悬念式（抛出问题）
2. 金句式（提炼观点）
3. 数字式（具体清单）
4. 对比式（制造冲突）
5. 场景式（描绘画面）

### 4. 文章生成
- **文本版**：纯文本格式，适合直接发送，保存为 `{节气名}-节气文案.txt`
- **HTML版**：公众号排版版，参考 `references/article_template.md` 的排版规范，保存为 `{节气名}-节气文案-公众号版.html`

## 排版规范
- **最终版排版规范**：详见 `references/article_template.md`
- **关键格式要求**：
  1. 装饰元素必须使用边框方案：`border-top:1px solid #9B8AA5;width:32px;margin:0 auto 24px;`
  2. 所有样式必须内联
  3. 正文字号15px，主标题字号20px
  4. 固定关注引导语在文末
  5. 彳亍时刻标题使用淡紫色#9B8AA5
- **重要**：此格式已通过用户测试，确保公众号编辑器可复制

## 使用示例
用户：「帮我生成小满的节气文案」
1. 读取 `references/solar_terms_2026.md` 获取小满日期（5月21日）和三候
2. 读取 `references/psychology_themes.md` 获取小满心理主题「适度与满足」
3. 选择标题策略（如金句式：「小满，刚刚好就是最好」）
4. 生成文本版和HTML版文案
5. 保存到工作目录
