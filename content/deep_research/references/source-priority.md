# 来源优先级

本文件用于说明不同研究任务中，优先应该查什么来源、如何判断来源质量，以及何时需要补充验证。

## 一、通用来源优先级

默认按以下顺序取证：

1. **原始来源**
   - 官方文档、标准、法律法规、政策原文
   - 学术论文原文、会议论文、期刊论文、预印本
   - 公司财报、监管披露、产品发布说明、源码仓库、变更日志
   - 政府数据库、机构统计库、原始数据集
2. **高质量二手来源**
   - 行业报告、研究机构分析、专业媒体深度报道
   - 权威数据库的聚合页面
3. **辅助来源**
   - 技术博客、论坛讨论、问答社区、社交媒体

辅助来源只能用来发现线索、补充案例或验证社区感受，不能单独支撑关键结论。

## 二、按场景选择来源

### 1. 学术研究 / 论文综述

优先来源：

- Google Scholar / Semantic Scholar
- arXiv、SSRN、bioRxiv 等预印本平台
- 会议与期刊官网
- 学校、实验室、研究机构官网

关注点：

- 是否为原始研究、综述、元分析或 benchmark
- 作者、机构、年份、发表 venue
- 方法是否清楚，样本或实验设置是否充分
- 是否能找到 DOI、补充材料、代码或数据集

### 2. 技术 / 产品研究

优先来源：

- 官方文档
- changelog / release notes
- GitHub 仓库、issue、RFC、技术博客
- 独立 benchmark 与第三方评测

关注点：

- 版本号和更新时间
- 是否为官方承诺还是社区总结
- 是否给出测试条件、限制、适用范围
- 是否存在“营销表述大于事实依据”的情况

### 3. 市场 / 公司 / 行业研究

优先来源：

- 财报、招股书、监管文件
- 政府统计、公协会报告、研究机构数据库
- 公司官网、投资者关系页面
- 可靠媒体和行业研究报告

关注点：

- 数据口径是否一致
- 时间区间是否一致
- 是公司自报还是第三方统计
- 是否存在样本偏差和利益相关

### 4. 政策 / 法律 / 标准研究

优先来源：

- 法规原文、官方发布页面
- 标准组织官网
- 法院判决文书、监管问答、官方指南

关注点：

- 版本是否最新
- 是否适用于目标地区或行业
- 是正式规则、草案、征求意见稿还是解读文章

## 三、建议的检索路径

建议采用“宽搜 -> 深读 -> 核验”的三段式：

1. **宽搜**
   - 用 `search` 先扫清主题全貌
   - 找出高频来源、关键术语和主要争议
2. **深读**
   - 用 `url_fetch` 读取关键页面全文
   - 必要时补充作者、机构、方法、日期和数据口径
3. **核验**
   - 对关键数字、时间线、定义、结论做二次交叉验证
   - 动态页或抓取失败时，用 `browser` 落到原始页面

## 四、判断来源质量时必问的 5 个问题

1. 这是谁写的，机构是否可信？
2. 这是什么时候发布或更新的？
3. 它引用的是原始证据，还是转述别人的内容？
4. 方法、样本、统计口径是否说明清楚？
5. 作者或发布方是否存在明显利益相关？

## 五、处理冲突来源

如果两个来源结论冲突，不要直接二选一。先判断：

- 是否因为时间不同
- 是否因为研究对象或样本不同
- 是否因为定义口径不同
- 是否因为一个是原始来源、另一个只是转述
- 是否因为一个是正式发布，另一个只是预测或评论

通常优先选择：

- 更新更明确的来源
- 更接近原始数据的来源
- 方法说明更充分的来源
- 与其他高质量来源更一致的来源

如果仍不能消解冲突，就在正文中显式保留争议，并说明目前无法最终裁定。
